# Control plane

- All interactions and commit messages: extreme concision; grammar may yield to brevity.
- Before staging changes for commit, committing, or pushing, obtain explicit user permission in the current turn. Approval never carries forward; local edits need no permission.
- Before destructive Git operations—including `reset --hard`, force-push, branch deletion, or checkout over local changes—obtain explicit user permission in the current turn.
- Give no completion summary unless requested.
- End each plan with concise unresolved questions, if any.
- For GitHub operations, prefer `gh`.
- Before writing, modifying, or reviewing code, read `~/.claude/CODING_STANDARDS.md`.
